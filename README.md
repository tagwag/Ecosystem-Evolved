# Ecosystem-Evolved

Working copy of [tagwag/Ecosystem](https://github.com/tagwag/Ecosystem) for porting the simulation
and adding evolvable brains (run-and-tumble → C. elegans → fly larva → adult fly connectomes).

**The original repo is left untouched.** All new work happens here.

## Layout
- `java-original/` — the Java project exactly as it was, including the newer (late 2022 – Feb 2023)
  changes from the local Mac copy that were never pushed to the original repo:
  `Pathfinding`, `Bacillus` / bacteria body types, `Vector2D`, `Notes`, and Environment/CellOrFood edits.
- (coming) `python/` — the Python port with evolvable brains.
