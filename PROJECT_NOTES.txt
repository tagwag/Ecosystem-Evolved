=== MODEL BASICS ===
- World: 1920x1080, patchy food, cells smell only concentration at their own spot (no direction).
- Body rules from the Java Cell.java (size slows you, food = 100 energy, size +10 per food).
- Worm brain: real C. elegans connectome (Cook 2019, OpenWorm c302): 300 neurons + 95 muscles,
  4,562 chemical synapses, graded rate model. Genome = one strength gene per synapse + gains + decoder.
- Fair test = one genome copied to 40 worms on unseen worlds, same layouts for every condition.

=== RESULTS SO FAR (short) ===
Step 1 tiny evolved brain: 1.7x random walk.
Step 2 worm connectome: 4.4x random walk. Evolution mostly prunes. Brain is highly redundant
  (no single neuron/synapse matters; mutational robustness). Evolved wiring survives food scarcity, random doesn't.
Step 3 hunger peptide (broadcast signal, evolvable receptor per neuron): no effect.
  Open readout (decoder reads all 300 neurons): evolution skips command neurons AVA/AVB, reads smell
  sensors + first relays (ASE, AWC, AWA, AIY, AIZ). Weakens the old "rediscovered AVB" claim.
Step 3b hunger + scarce food (4 seeds): weak hint.  Step 3c (12 seeds): NOT confirmed (p=0.64 energy,
  p=0.33 slowing-when-full; direction right 8/12 vs 4/12). Cause: resting saves too little energy.
Step 4 brain growth (duplicate neuron / new neuron / new synapse, cap 50): brains grew 3-6 neurons by
  DRIFT; growth selected at chance rate = neutral. Lesson: new parts need a new job in the world.
Step 5 (running 2026-11-01): lifetime learning ladder in a TWO-ODOR world (food odor vs decoy odor,
  meaning flipped randomly per world so only lifetime learning can solve it):
  fixed -> hebb -> dopamine (three-factor, reward on meals) -> curiosity (reward for surprise) -> sleep
  (periodic downscaling of learned weights) + branch "sprint_rest" (dopamine + bonus for quick trips to
  food + reward for long rests). Code: ecosim/worm5.py, ecosim/step5.py. Results -> results/step5_*.

=== KNOWN ISSUES / FIXES ===
- 2026-11-01 FIXED: food-tie bias. world.eat() let agents eat in list order and evolution puts elites first,
  so parents won food ties. Now random order each tick (own RNG, layouts unchanged). Steps 1-4 + 3b/3c were
  run with the bias: their FAIR TESTS are unaffected (identical genomes), but evolution itself was slightly
  tilted toward parents. Steps 5 and 6 were restarted with the fix.
