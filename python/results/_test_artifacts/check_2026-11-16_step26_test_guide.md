# Knockout guide: what happens when one neuron is removed

Generated by `python -m ecosim.step26 analyze` from 3 neurons x 2 evolved brains (Step 23 control, generation 300), each tested on 2 unseen worlds as 60 clones. Method and rules: python/ecosim/step26.py and python/ecosim/STEP26_KNOCKOUT_GUIDE_DESIGN.md.

**How to read a line:** the change in each measure when that neuron is removed, versus the same intact brains on the same worlds. Only changes that pass the 5 % false-discovery-rate test are listed; "no detectable effect" means none passed. (D) = the motor decoder reads this neuron directly, so part of its effect comes from the readout design, not the wiring.
