# Factor guide: footnotes for the experiment form

Every `[tag]` in `configs/TEMPLATE.toml` (and in the GUI) points to a section here. Generated by `make_form.py` from the factor catalog and the engine code; edit those, then regenerate.

**Modes:** `off` = the factor doesn't exist in the world (the equilibrium baseline). `auto` = autopilot, realistic values chosen from the research (listed per factor below). `custom` = start from the defaults listed below and change what you set.

**Evidence tags:** EVO = shown to drive evolution; EFFECT = changes fitness or behaviour; CONTESTED = disputed; UNTESTED = no C. elegans study found. CONTESTED/UNTESTED factors appear only in the GUI's Researcher mode.

**Every factor is a simplified model** of the effect the studies describe (energy cost, speed, death chance, fertility, mutation, senses), not biochemistry. Model units are explained per factor.

## Run settings

### [R1] run.name
Default: `"unnamed"`. Name of the experiment; results are saved as results/<name>.json/.png/_stats.txt.

### [R2] run.replicates
Default: `30`. How many independent worlds per arm (each with its own food layout and founder). More = more reliable statistics. 30 is a good default; >= 16 is needed for paired tests to be able to reach p < 0.05 after correcting for several comparisons.

### [R3] run.ticks
Default: `50000`. How long the run lasts. One tick = one step of every worm. ~6,000 ticks is one worm lifetime (max_age); 50,000 ticks is roughly 10-20 worm generations at equilibrium.

### [R4] run.arms
Default: `["frozen", "shadow", "real"]`. Which versions of the world to run side by side. frozen = no mutation (checks the code; must show zero genetic change), shadow = random survival (chance alone), real = natural selection. Adaptation = real minus shadow. 'shadow' needs 'real'.

### [R5] run.seed
Default: `1`. Random seed. The same seed + the same form = the same run (on the same machine).

### [R6] run.founders
Default: `"toybrain_fair"`. Which brains start the worlds: toybrain_fair (evolved champions of the toy-brain fair run, one per replicate), toybrain (original run), random (unevolved; they usually starve), or a path to a results file.

### [R7] run.every
Default: `500`. Measure every N ticks.

## World settings (the equilibrium baseline)

### [W1] world.size
Default: `400.0`. Arena width and height (units). 400 x 400 holds ~380 worms with the default food.

### [W2] world.patches
Default: `80`. Number of food patches (fixed spots unless food_layout moves them).

### [W3] world.patch_r
Default: `4.0`. A worm eats when within this distance of a patch centre.

### [W4] world.food_max
Default: `20.0`. Most food a patch can hold.

### [W5] world.regrow
Default: `0.01`. Each tick a patch regrows this fraction of what's missing. Sets the carrying capacity.

### [W6] world.bite
Default: `0.5`. Most food one worm eats per tick; worms crowding a patch share it.

### [W7] world.sig_smell
Default: `25.0`. How far food smell reaches (long range, AWA/AWC-like).

### [W8] world.sig_taste
Default: `5.0`. How far taste reaches (short range, ASE-like).

### [W9] world.e_start
Default: `10.0`. Energy of founders.

### [W10] world.e_split
Default: `20.0`. A worm splits in two when its energy reaches this.

### [W11] world.cost_base
Default: `0.02`. Energy burned per tick just living (scaled by temperature if that factor is on).

### [W12] world.cost_move
Default: `0.02`. Extra energy per tick per unit of speed.

### [W13] world.max_age
Default: `6000`. Death of old age (the same for every genome, so it is not selection).

### [W14] world.mut_sigma
Default: `0.1`. Mutation size per gene for a child, before scaling by genome size and mutation factors.

### [W15] world.slots
Default: `640`. Most worms a world can hold (memory). Keep above the carrying capacity.

### [W16] world.start_fill
Default: `0.25`. Fraction of slots filled with founders at the start.

### [W17] world.trait_cost
Default: `0.005`. Energy per tick per unit of each resistance/ability trait (abilities aren't free).

### [W18] world.dauer_cost
Default: `0.002`. Energy per tick while in the dauer resting stage.

#### [F1] temperature  (EVO; GUI level: easy)

**Real-world forms:** constant level, spatial gradient (thermotaxis), daily cycle, seasonal cycle, heat shock (short spike), cold shock, extreme heat (>25 C sterility in real worms), random fluctuation.

**What the research says:** Changes development rate, fertility, lifespan and competition with C. briggsae (warmer favours briggsae).

**Real range:** lab 15-25 C; fertility collapses above ~25-26 C; dauers survive wider

**How the engine models it:**

```
Field in degrees C. Metabolism follows Q10 (cost_base x q10^((T-20)/10)); fertility collapses above ~25-26 C;
the heat_tol trait shifts the upper limit. Senses: temperature (AFD-like) and its change over time.
```

**Custom defaults:** `{ field = { space = "uniform", level = 20.0 }, q10 = 2.0, effects = { ok_low = 16, ok_high = 24, below = { speed = -0.04, fert = 0.05 }, above = { cost = 0.002, death = 0.0003, fert = 0.4 } } }`

**Autopilot (auto) changes:** `{ field = { space = "gradient", low = 15.0, high = 25.0, time = "cycle", period = 20000, amplitude = 0.05 } }`

### Category: radiation

#### [F14] radiation  (EVO; GUI level: easy)

**Real-world forms:** UV-A (320-400 nm), UV-B (280-320 nm), UV-C (100-280 nm), X-ray, gamma (e.g. Cs-137, Co-60), alpha particles, beta particles, neutrons, protons, heavy ions / cosmic rays (space), radon (alpha emitter, soil gas), chronic low dose over many generations, acute high dose, spatial hotspot (contaminated patch), solar events (bursts of UV / particles).

**What the research says:** Chornobyl nematodes showed no genome damage signature; DNA-repair genes set sensitivity (2x in repair mutants).

**How the engine models it:**

```
Radiation as a MUTATION SOURCE (its main biological effect) plus fertility loss and death at high dose.
params.sources = {form: dose_rate} in Gy per 1000 ticks; params.field = where it is (uniform/hotspot/...; the
field's level is a 0..1 multiplier). Effective dose = sum(weight x rate). Effects per unit effective dose:
mutation x(1 + mut_per_gy x dose x (1 - repair)), fertility - fert_per_gy x dose, death chance death_per_gy x dose.
The 'repair' trait (DNA repair, costs energy) removes that fraction of the damage.
```

**Custom defaults:** `{ sources = {  }, field = { space = "uniform", level = 1.0 }, mut_per_gy = 2.0, fert_per_gy = 0.05, death_per_gy = 2e-05 }`

**Autopilot (auto) changes:** `{ sources = { gamma = 0.002, radon = 0.0005, uv_b = 0.01 }, field = { space = "uniform", level = 1.0 } }`

**Sources:**

#### [F21] pathogen_bacteria  (EVO; GUI level: easy)

**Real-world forms:** fixed pathogen, coevolving pathogen (Red Queen), avoidable vs unavoidable, lethal vs sub-lethal.

**What the research says:** Coevolving Serratia kept outcrossing; without it populations went back to selfing.

**How the engine models it:**

```
Bacterial pathogen living on `frac_patches` of food patches; eating there gives `infect` chance per tick.
Infected worms smell of it nearby (pathogen sense = level of infected food in range) so avoidance can evolve.
mode 'fixed' or 'coevolving' (Red Queen): the pathogen's counter-adaptation tracks the population's mean
resistance with lag `lag` ticks, so resistance only helps while it is ahead.
```
